# Code of conduct

SOCOM Legacy is a community project. We want it to be a place where anyone who loves the game can show up, contribute,
and be treated with respect, whatever their experience, background or identity.

We adopt the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as
our code of conduct. In short:

- **Be respectful.** Disagree about the code, not the person. Assume good faith.
- **Be welcoming.** Help newcomers find their footing; everyone started somewhere.
- **No harassment.** No insults, slurs, personal attacks, unwelcome attention, or sharing someone's private information.
- **Keep it on topic.** Issues and pull requests are for the project; trash talk belongs in the match.

It applies here on GitHub, on the SOCOM Legacy Discord, and in games and events run by the community.

## Reporting

If something happens that breaks this code, tell a moderator: **Acidragon** (Community Moderator) or **Machete**
(Competitive Scene Moderator) on the [SOCOM Legacy Discord](https://discord.gg/RrtTEdvECV), or a project maintainer.
Reports are handled privately, and nobody is penalised for reporting in good faith.

Moderators may remove content, warn, or suspend or ban anyone whose behaviour breaks this code, following the
Contributor Covenant's enforcement guidelines.
