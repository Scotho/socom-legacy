waiting for a disc image

Nothing is uploaded. The image is read here, in this browser, a piece at a time, and it never leaves this machine. Nothing is kept either: the next visit asks for it again.

An .iso of 2048-byte sectors, as a DVD drive or a mounted disc gives it. A raw .bin / .img of 2352-byte sectors is refused by name.

    About dev build

    Not a port and not emulation. No game code runs. The disc's own data — geometry, textures, scene graph, lighting, fog — is read and drawn again in TypeScript, so it is a reading of the game and a reading can be wrong.

    Known to differ: blended surfaces are sorted by the browser where the engine traversed its grid outward from the camera, the frame brighten is a fixed value where the game meters it, the alternate states a map holds (destroyed, unlit, far LOD) are hidden rather than switched by play.

    Play is a reading of the game's rules, not the game: no game code runs there either, and what it gets wrong is listed in the README's known gaps.
