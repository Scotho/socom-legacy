**Status: Forge, local only.** Codex connects to the Forge or the solo test room open in your browser, never a lobby or
an online match. Codex's registration, guest sign-in and login were checked against Codex CLI 0.162.1 on Windows (the
compatibility record), on the earlier panel and its earlier sign-in wording; the one-link flow itself is not measured
yet.

This page follows the card's three moments -- Connect, Allow, Connected -- for Codex. What connecting means, the
permissions, staying connected and how to disconnect are on [Connect an agent](/connect/).

## 1. Connect

In the page, open **Connect an agent** and choose **Codex**.

### First time with Codex?

The box shows the two lines to run once, in a terminal where Codex runs (**Add and log in**; "Run this once where your
agent runs."). With the production connection service:

```sh
codex mcp add socom2legacy --url https://agent.socom2legacy.com/mcp
codex mcp login socom2legacy
```

The card's **Connection service** box shows the address in use: copy the box's lines rather than this page's when they
differ. A developer running `npm run forge:agent` gets `http://127.0.0.1:5360/mcp` in its place.

"Then sign in: codex mcp login socom2legacy opens the connection service’s guest sign-in in your browser." That page
asks "Allow Codex to sign in to SOCOM 2 Legacy as a guest?" (the name is the one Codex reports) and says "This only
lets it ask to connect. You still press Allow on your own page before it can do anything there." Press **Approve**.
The request ends in five minutes.

Once this browser has connected Codex, the box starts folded.

### Copy connect link

Press **Copy connect link**. It copies one line:

```text
Connect to my SOCOM 2 Legacy page: https://agent.socom2legacy.com/join/<code>
```

"Paste it into Codex. You’ll approve here." The link works once and expires in five minutes; the card counts down
("Link expires in 4:59"). If the browser does not let the page write to the clipboard, the card shows the line to
select and copy yourself ("Copy failed · Select and copy the link below").

Paste the link only into your own agent, and never share it -- not in a chat, a stream or a screenshot. Anyone
holding it can ask to connect within its five minutes, and the Allow card shows the name the caller reports for
itself.

*Screenshot: `connect/codex-connect.png`, not on this site yet.* It is added in the screenshot pass.

## 2. Allow

The card says "Codex wants to connect". Every permission Codex asked for is a switch, all on. Turn off any you do not
want, then press **Allow** (or **Decline**). Tick "Remember Codex on this browser" to make the next connect a single
Allow with the same switches. The small print "Check: the code … matches your agent's" is there if you want to compare
it with the code Codex reports; it is not a step.

*Screenshot: `connect/codex-allow.png`, not on this site yet.*

## 3. Connected

The card shows Codex's name, each permission as a chip (on or off), the recent activity, the note box ("Tell your
agent…"), the local files and **Disconnect**.

*Screenshot: `connect/codex-connected.png`, not on this site yet.*

## Troubleshooting

| what the card says | what to do |
|---|---|
| "Connect failed: The connection service is not hosted for this page yet." | A production build: no service answers at this address. Check the **Connection service** box, or press **Try again** later. |
| "Connect failed: Start the local connection service and page with npm run forge:agent, then try again." | A development build: no local service answers. Run `npm run forge:agent`, then **Try again**. |
| "Connect failed: The connection service is busy. Try again shortly." (or "… is unavailable …", "… did not answer in time …") | The service is there but cannot take the request now. Wait, then **Try again**. |
| "Connect failed: The connection service does not accept this page's address." | Press **Check the connection service address**: this page names a service that does not serve it. |
| "The link expired. Copy a fresh one." | Five minutes passed before Codex connected. Press **Copy a fresh link** and paste the new line. |
| "The direct route between this page and the connection service did not open. A firewall or this network may block it." | Press **Try again**; if it fails again, try another network (**Details** lists the routes tried). |
| "Connect failed: Keep this page visible while connecting your agent." | Keep the tab in view while you press **Copy connect link**. |
| "Paused while this tab is hidden: come back to run tests again." | Not a failure: Codex is still connected. Bring the tab back; a test that was running was stopped, and Codex sends it again. |
| "Connect failed: Too long passed since the reload to reconnect. Connect again with a fresh link." | Reconnect lasts two minutes after a reload. Press **Copy connect link** again. |
| no socom2legacy tools in Codex, or it says it is not logged in | Run `codex mcp login socom2legacy` and approve the sign-in page. |
