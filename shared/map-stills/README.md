# Map stills -- one framed view per map

The owner's own stills of the 22 maps (Craig, 2026-11-08), each a PNG and a JSON that names the Forge camera it was
taken from (`camera`: x, y, z, yaw, pitch) and the build. Kept in git on the owner's word (2026-11-09, seat a3: "make
sure these are included in the repo (my word)"), an exception to RS.R8 named in the LCM plan's ruling LCM.R6.

**Used by:** the LIVE lobby card, the post-match card and the `/match/<id>` page's header (LCM), the replay viewer's
match preview and rich invite links (`manifest.json`'s purpose), and -- the owner's word -- the Forge's starting camera
when a map's base opens (each JSON's `camera`).

**Not** a build asset by default: a build ships them only where the LCM plan or a later plan says.
